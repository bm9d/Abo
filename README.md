# Markdown Static Website

A simple, modern static website that renders markdown content with syntax highlighting.

## Features

- Clean and responsive design
- Markdown content rendering
- Syntax highlighting for code blocks
- Mobile-friendly layout
- Easy to customize

## How to Use

1. Clone this repository
2. Open `index.html` in your web browser
3. Edit `content.md` to update your website content
4. Customize `styles.css` to change the appearance

## File Structure

- `index.html` - Main HTML file
- `styles.css` - CSS styles
- `content.md` - Markdown content
- `README.md` - This file

## Customization

### Changing Content
Edit the `content.md` file to update your website content. The file supports all standard markdown syntax.

### Changing Styles
Edit `styles.css` to modify the website's appearance. The file uses CSS variables for easy customization of colors and other properties.

## Dependencies

- [marked.js](https://marked.js.org/) - Markdown parser
- [highlight.js](https://highlightjs.org/) - Syntax highlighting
